# Assistant(e) Pro

**Guide & Boîte à Outils d'Excellence** pour assistant(e)s de direction et secrétaires.

Application complète construite avec **TanStack Start** (React + TanStack Router + Vite + Tailwind CSS).

## Fonctionnalités

- **Tableau de Bord** : vue d'ensemble + progression
- **Formation & Quiz** : 5 modules avec mises en situation pratiques
- **Générateur de Mails** : 5 modèles professionnels éditables
- **Matrice d'Eisenhower** : prioritisation des tâches
- **Check-list Journée** : routine quotidienne
- **Simulateur d'Appel** : prise de notes téléphoniques structurée

La progression est sauvegardée localement (localStorage).

## Démarrage

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm run preview
```

## Stack

- TanStack Start / TanStack Router
- React 19
- Vite 6
- Tailwind CSS 4
- TypeScript
